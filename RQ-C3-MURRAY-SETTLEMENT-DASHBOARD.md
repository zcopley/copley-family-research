# RQ-C3 Murray Settlement Dashboard

## Question

Was the Lewis County Irish Catholic settlement around the Copleys connected to a Murray / Murry anchor family before the 1843 Copley land purchase?

## Current Answer

The Murray Settlement remains a useful research framework, but the direct pre-1843 John Murray deed path is exhausted. The strongest current Murry evidence is post-1850: Luke Murry / Anne Loghan, adult Patrick Murry, James Murray, tax-list appearances in 1854 and 1857, and Irish cluster evidence in 1860/1870.

No independent record has yet identified the older **Luke Murry + Margaret Murry** couple named as adult Patrick's parents.

## Evidence Status

| Evidence | Status | Use |
|---|---|---|
| Direct John Murray deed path | Closed | Old 1826/1833 leads are 1899 oil-lease misindexes; exact Murray grantee search has no pre-1843 hit. |
| 1850 Lewis County census | Complete | Copley household found; no dense Irish cluster around it. |
| 1860 Lewis County census | Complete with image capture | Confirms Luke Murry household and adult Patrick Murry, plus rural Dolan / Irish cluster. |
| 1870 Lewis County census | Complete with corrections | Confirms Battelle / Willey Irish clusters; adult Patrick remained in Lewis County; Luke moved to Rhode Island. |
| Personal-property tax work | Extensive browser image work | Confirms James Murray and Patrick Murry in 1854/1857; no older Luke / Margaret found. |
| Luke Murray / Anne Loghan marriage register | Found | Confirms marriage but no witnesses, parents, or bondsman. |
| Online bond / consent and Smith index | Negative | Remaining bond path is direct courthouse request. |

## Next Records

1. ORT-005: Direct Lewis County courthouse request for Luke / Anne original bond, consent, surety paper, or bond-book entry.
2. ORT-015: 1852-1860 deed / court / probate / church follow-up for older Luke and Margaret, adult Patrick, James Murray, and Loghan associates.
3. ORT-016: St. Michael's / early Catholic sacramental registers.
4. ORT-023: Map and land-record work tying Battelle / Willey / Weston to Cove Lick / Camden / Loveberry.

## Guardrail

Do not treat the Murray Settlement name or post-1850 Murry evidence as proof of a pre-1843 Murray anchor family.
