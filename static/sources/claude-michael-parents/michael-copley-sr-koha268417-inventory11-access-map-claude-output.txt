2. Assessment: Does koha:268417 Contain Anything Related to Order Book 1-A?

No. Koha:268417 is entirely composed of an alphabetical and chronological court case index running 1817-1932 (loose-paper court actions, not probate/fiduciary order books) plus loose-paper court record boxes from 1817-1875.

It contains no bound order books, no fiduciary volumes, no probate registers, no appraisements, and no settlement books. Order Book 1-A is not here.

The chronological index film DGS 8727996 (Film 249807, 1870-1913) covers the 1897 probate period and may index Copley's case number within the regular County Court docket, but it will not contain the fiduciary/probate order book text itself.

6. Where Is Order Book 1-A?

Order Book 1-A is a fiduciary/probate order book, a separate volume series in which the County Court entered estate and fiduciary orders. It is distinct from the regular law docket order books in koha:81956.

The FamilySearch catalog for Lewis County WV has no entry for fiduciary order books, settlement books, or commissioner-of-accounts books filmed after 1882. This record type was not included in the 1970 GSU filming project that captured wills, inventories, and regular order books. The volumes likely remain at the Lewis County Courthouse in Weston, WV.
