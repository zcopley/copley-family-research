RELIABILITY ASSESSMENT

The WV County Death Register entry is a primary record for the death event but a secondary and potentially unreliable source for parent information. Death registers of this era recorded what an informant or recorder supplied at the time of death. The same row's Bridget-as-wife error shows confusion about family relationships, so the John / Sarah parent names should be treated as important evidence but not final proof.

The Dolan maiden name for Sarah does not appear in the official death record index or original image. It was not found in this search in FindAGrave or FamilySearch historical records tied to this Michael Copley. It probably derives from user-submitted trees, family inference, AI-generated synthesis, or another unverified secondary path until an original record names Sarah as Dolan.
