PROOF box: "No. 30"

At the top of the PROOF box, above the category list, the handwritten number "No. 30" appears. In Virginia personal-property-tax records of this era, this "No." typically records the page number of the taxable-persons list being summarized on that proof sheet. If so, this is the proof for taxable-persons page 13, meaning page number 30 of the combined book or the 13th page of this district. The adjacent image i3811884-00375 is known to be taxable-persons page 14, which is the next page, confirming these are consecutive pages in the same continuous district book.
